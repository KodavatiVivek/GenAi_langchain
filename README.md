# GenAI LangChain Projects

## 📋 Overview
This repository contains cutting-edge projects built with LangChain and LangGraph frameworks. These projects demonstrate the integration of Large Language Models (LLMs) with various AI-powered applications for building intelligent, conversational, and autonomous systems.

## 🎯 Use Cases
- **Conversational AI Applications**: Building chatbots and conversational interfaces powered by LLMs
- **LangGraph Workflow Automation**: Creating complex workflows and agent systems using LangGraph
- **RAG (Retrieval Augmented Generation)**: Implementing context-aware question answering systems
- **Multi-Agent Systems**: Developing systems where multiple AI agents collaborate to solve problems
- **LLM Chain Orchestration**: Managing complex chains of LLM calls with custom logic

## 🛠️ Tech Stack

### Core Framework
- **LangChain** - Framework for developing applications powered by language models
- **LangGraph** - Building stateful, agentic applications with LLMs

### Programming Language
- **TypeScript** - Primary language for type-safe development

### Key Technologies
- **Node.js** - Runtime environment
- **LLM Integration** - Support for various language models (OpenAI, Claude, etc.)
- **Vector Databases** - For embeddings and semantic search
- **API Integration** - RESTful and GraphQL endpoints

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn package manager
- API keys for LLM providers (OpenAI, Claude, etc.)

### Installation
```bash
# Clone the repository
git clone https://github.com/KodavatiVivek/GenAi_langchain.git
cd GenAi_langchain

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Add your API keys to .env file
```

### Running Projects
```bash
# Build the TypeScript code
npm run build

# Run a specific project
npm run start

# Development mode with hot reload
npm run dev
```
